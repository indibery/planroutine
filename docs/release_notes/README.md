# 릴리즈 노트

App Store "이번 버전의 새로운 기능"에 들어가는 글. `release` 레인이 여기서 읽어
App Store Connect에 자동 입력한다.

## 규칙

- 파일명: `<pubspec 버전>.ko.txt` (예: `1.2.0.ko.txt`)
- **버전을 올리면 이 파일을 먼저 만들어야 한다.** 없으면 `release`가 가드 E로 중단한다.
  Apple은 업데이트 심사에 이 항목을 필수로 요구하므로, 비어 있으면 어차피 제출이 막힌다.
- 사용자 관점으로 쓴다 — "리팩토링했습니다"(X) / "~할 수 있습니다"(O)
- git에 두는 이유: 스토어에 나가는 글도 리뷰 대상이고, 어느 버전에 무엇을 알렸는지가
  기록으로 남는다.
