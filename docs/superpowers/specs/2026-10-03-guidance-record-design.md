# 지도 기록 탭 — 설계

날짜: 2026-10-03 · 선행: `2026-10-02-feature-modules-design.md`(기능 모듈), `2026-10-03-module-settings-design.md`(기능별 설정), `2026-10-03-postit-design.md`(첫 탭형 선택 기능)
시안: Claude 디자인 캔버스 https://claude.ai/artifact/TZqMALfDBjXi1uWZyG5WkC — 7화면(잠금·목록·기록 쓰기·녹음·기록 보기·수정 이력·명단 관리).
**용어:** 이 문서의 `판`(revision)은 화면에서 `수정 버전`이다 — 판 1은 `처음 작성`, 판 n은 `수정 버전 n-1`. 화면 문구에 `판`을 쓰지 않는다(사용자 결정 2026-10-03).
시안은 이름이 `상담 기록`이던 때 그렸다. 구분·진행 상태·판단·조치 칸·사진 첨부는 시안 뒤에 결정됐으므로 이 문서가 우선한다.

## 배경과 목표

사용자 요청(2026-10-03): 학교폭력 사안이나 교권이 무너지는 상황에 대비해 **있었던 일을 그때그때 기록해 두는 곳**.
상담 실적을 정리하려는 것이 아니다.

**범위는 학교 단계다**(사용자 확정):
- 학교폭력 사안이 교육청(전담조사관)으로 **이관되기 전**의 사전 조사·초기 대응
- 학교 안에서 마무리될 만한 **가벼운 사안**(생활지도 수준)
- **교육활동 침해**로 볼 수 있는 일(주로 학부모 민원·폭언)

이관 뒤의 조사·증거 수집은 이 탭의 몫이 아니다. 그래서 목격자 진술 관리나 학생 제출 증거 수집 같은 기능은 두지 않는다.

성공 기준:
- 사건 직후 몇 분 안에 사실·들은 말·조치를 남길 수 있다.
- 나중에 "처음에 뭐라고 썼는지"와 "언제 고쳤는지"를 보여 줄 수 있다.
- 휴대폰을 남이 잠깐 만져도 기록이 보이지 않는다.
- 한 사람(학생·보호자)과 얽힌 기록을 모아 볼 수 있다.

## 결정 (사용자 선택, 2026-10-03)

| 질문 | 결정 |
|---|---|
| 기록 형태 | 상담 일지형 — 날짜(사건 시각) 단위로 한 건씩 |
| 사람 지정 | ~~명단을 먼저 만든다~~ → **이름을 바로 쓰고, 저장한 이름은 자동으로 명단에 기억해 다음에 추천한다**(2026-10-04 실기기 피드백 — 명단을 따로 관리하는 것이 번거롭다). 같은 이름 = 같은 사람. 학생·보호자 구분은 묻지 않고 소속은 이름에 같이 쓴다(`박서준(5반)`) |
| 관련인 역할 | **붙이지 않는다**(가해·피해·목격 모두). 이유를 입력 칸 아래에 안내한다 |
| 수정 | **판을 쌓는다** — 저장할 때마다 새 판 추가, 이전 판은 고치거나 지우지 않음 |
| 삭제 | 탭 안 `삭제한 기록`으로(공용 휴지통 아님). **30일 자동 삭제에서 제외**, 영구 삭제는 사용자가 직접 |
| 시각 | 사건 시각(입력, 정확/날짜만/대략) + 기록 시각(자동, 불변) |
| 칸 | 제목 · 장소 · 관련인 · 경과(사실) · 들은 말 · **판단·조치** |
| 기록 구분 | `생활지도` / `교육활동 침해` |
| 진행 상태 | `진행 중` / `학교에서 마무리` / `교육청 이관` |
| 녹음 | 첫 판에 **앱 안 대면 녹음 + 파일 가져오기** 둘 다 |
| 녹음 중 화면 | **켜 둔다**(백그라운드 녹음 없음). 앱을 떠나거나 전화가 오면 그때까지 저장 |
| 사진·스크린샷 | 첫 판에 넣는다(주로 교권 사안의 문자·메신저 캡처) |
| 첨부 원본 | 변환 없이 바이트 그대로 보존 + **SHA-256** 기록 |
| 잠금 | Face ID·지문·기기 암호. **한 번 풀면 지도 기록을 떠난 지 15분까지 다시 묻지 않는다**(떠남 = 탭 이동·앱 백그라운드). 앱을 완전히 종료하면 처음 한 번은 묻는다 |
| 탭 이름 | **`지도 기록`** — 탭 바에 `학폭`·`교권` 같은 낱말이 드러나지 않는다 |
| 범위 안내 | 기능 설명과 빈 화면에 한 줄 |
| Android 백업 | **첨부 파일은 백업에서 뺀다**(DB·글 기록은 백업) |
| 미룬 것 | PDF·원본 내보내기(다음 판에 함께), 사안 묶음·타임라인, 유형 태그, 음성→텍스트 |

기각한 것:
- **해시 사슬**(판마다 이전 판 해시) — 외부 기관의 시각 증명이 없으면 사슬 전체를 새로 만드는 조작을 못 막는다. 복잡도에 비해 증명력이 늘지 않는다. PDF 내보내기 때 외부 앵커와 함께 다시 본다.
- **추가 기록만 허용(수정 금지)** — 오타 하나도 덧붙여 정정해야 한다. 판 쌓기도 원문이 남아 엄격함에서 크게 뒤지지 않는다.
- **목격 표시** — 목격자 진술은 이관 뒤 절차다. 초기 기록에서는 경과에 "누가 봤는지"를 적으면 된다.
- **백그라운드 녹음** — iOS 백그라운드 오디오 심사 질의, Android 14 마이크 포그라운드 서비스 신고서가 따라온다. 긴 녹음은 음성 메모 앱으로 녹음해 가져오면 된다.

## 데이터 (DB v9 → v10)

기존 테이블은 건드리지 않는다. 새 테이블 넷.

### `guidance_people` — 명단

| 칸 | 형 | 뜻 |
|---|---|---|
| `id` | INTEGER PK | |
| `name` | TEXT NOT NULL | |
| `role` | TEXT NOT NULL | `student` / `guardian` / `staff` / `other`(모르는 값은 `other`) |
| `memo` | TEXT | 소속·관계(예: `3반`, `민준 어머니`) |
| `archived_at` | TEXT | NULL=현재, ISO=보관(지난 학년) |
| `created_at`, `updated_at` | TEXT NOT NULL | |

- **기록을 저장할 때 관련인 이름마다 행을 확보한다**(없으면 넣고, 있으면 그 id) — 그 id가 판의 `personId`가 된다.
  같은 이름(앞뒤 공백 정리 후) = 같은 사람. `personId`는 이름에서 파생된 값이라 같은 내용 판정·바뀐 칸에서 뺀다
  (명단 이전에 쓴 기록을 그대로 저장해도 판이 생기지 않게).
- 쓰는 곳은 **관련인 칸의 이름 추천** 하나다. 추천을 길게 누르면 그 사람을 **보관**한다(추천에서 지우기) —
  보관한 이름을 다시 저장해도 되살리지 않고 그 id만 쓴다. 옛 기록에는 이름이 그대로 남는다(판이 이름 사본을 들고 있으므로).
- `role`·`memo` 칸은 남아 있지만 입력받지 않는다(새 행은 `student` 기본값, `memo`는 비움).

### `guidance_records` — 기록 몸통

| 칸 | 형 | 뜻 |
|---|---|---|
| `id` | INTEGER PK | |
| `created_at` | TEXT NOT NULL | **기록 시각.** 처음 저장할 때 찍고 어떤 경로로도 바꾸지 않는다 |
| `deleted_at` | TEXT | NULL=활성, ISO=삭제한 기록 |

### `guidance_revisions` — 판 (추가만)

| 칸 | 형 | 뜻 |
|---|---|---|
| `id` | INTEGER PK | |
| `record_id` | INTEGER NOT NULL | → `guidance_records` |
| `revision_no` | INTEGER NOT NULL | 1부터. `(record_id, revision_no)` UNIQUE |
| `saved_at` | TEXT NOT NULL | 이 판을 저장한 시각 |
| `kind` | TEXT NOT NULL | `guidance`(생활지도) / `infringement`(교육활동 침해) |
| `status` | TEXT NOT NULL | `open` / `closed_at_school` / `transferred` |
| `occurred_precision` | TEXT NOT NULL | `exact` / `date` / `approx` |
| `occurred_at` | TEXT | `exact`·`date`일 때 ISO. `approx`이면 NULL 가능 |
| `occurred_text` | TEXT | `approx`일 때의 문구(예: `3월 초~여름방학 전`) |
| `title` | TEXT NOT NULL | 한 줄 요약 |
| `place` | TEXT | |
| `participants` | TEXT NOT NULL | JSON `[{personId?, name, role, memo?}]` — **저장 시점 사본** |
| `facts` | TEXT | 경과(사실) |
| `quotes` | TEXT | 들은 말 |
| `actions` | TEXT | 판단·조치(지도 내용·보호자 연락·학교 보고·이관 일시) |

- **UPDATE·DELETE를 쓰지 않는다.** 예외는 영구 삭제 하나다(사용자가 `삭제한 기록`에서 직접). 가드가 리포지토리 소스를 훑어 지킨다.
- 구분·상태·사건 시각이 판 안에 있으므로 이것들을 바꾼 것도 이력에 남는다.
- 현재 내용 = 그 기록의 가장 큰 `revision_no`.
- **내용이 같으면 새 판을 만들지 않는다**(비교는 순수 함수).

### `guidance_attachments` — 첨부

| 칸 | 형 | 뜻 |
|---|---|---|
| `id` | INTEGER PK | |
| `record_id` | INTEGER NOT NULL | |
| `type` | TEXT NOT NULL | `audio` / `image` |
| `source` | TEXT NOT NULL | `recorded`(앱에서 녹음) / `imported` |
| `file_name` | TEXT NOT NULL | 앱 저장소 안의 이름 |
| `original_name` | TEXT | 가져온 파일의 원래 이름 |
| `sha256` | TEXT NOT NULL | 저장한 바이트의 해시 |
| `byte_size` | INTEGER NOT NULL | |
| `duration_ms` | INTEGER | 녹음일 때 |
| `captured_at` | TEXT | 녹음 시작 시각 또는 원본 파일의 생성 시각(알 수 있을 때) |
| `attached_at` | TEXT NOT NULL | |
| `removed_at` | TEXT | 첨부에서 뺀 시각. **파일은 지우지 않는다** |

- 첨부를 붙이고 뺀 기록은 수정 이력 화면에 시각과 함께 보인다.
- 파일은 기록을 영구 삭제할 때만 지운다.

### 마이그레이션

- `_onUpgrade`에 `oldVersion < 10` 분기로 네 테이블 + 인덱스(`guidance_revisions(record_id)`, `guidance_attachments(record_id)`).
- `_onCreate`도 같은 스키마.
- 실측: v9 판본에 일정·쪽지를 넣고 새 판본을 덮어 설치해 `user_version` 10 + 기존 데이터 유지를 확인한다.

## 파일 저장

- 위치: `getApplicationSupportDirectory()/guidance/`. 파일 앱·사진 앱에 보이지 않는다.
- 가져온 파일은 **변환·압축·자르기 없이 그대로 복사**한 뒤 스트림으로 SHA-256을 계산한다(2025.2.27 대법원 2022도1864 — 사본 증거능력에 원본 동일성, 해시 비교가 원칙).
- 앱 녹음: AAC `.m4a`, 모노 64kbps(1시간 약 30MB).
- 기록 보기에서 첨부를 누르면 해시값·원래 파일 이름·크기·시각을 보여 준다.
- **Android 백업**: 자동 백업은 앱당 25MB 상한이고 넘으면 백업 전체가 멈춘다(구현 전에 공식 문서로 재확인). 백업 규칙 파일(`fullBackupContent` / `dataExtractionRules`)로 `guidance/` 폴더만 뺀다 → DB·글 기록은 계속 백업된다. iOS iCloud 백업에는 앱별 상한이 없어 그대로 둔다.

## 화면

### 탭과 잠금
- 등록부 항목: `id: 'guidance'`(배포 후 바꾸지 않는다), 라우트 `/guidance`(설치와 무관하게 항상 등록), 이름 `지도 기록`, 탭형, 기본 꺼짐.
- 기능 설명: "학교 단계의 생활지도·교육활동 침해 기록을 남깁니다. 교육청으로 이관된 뒤의 조사는 전담조사관이 맡습니다." (문안은 구현 때 다듬는다)
- 잠겨 있을 때 탭에 들어오면 잠금 덮개 + Face ID 창 자동 호출. 실패·취소 시 덮개에 `잠금 해제` 버튼. 떠난 지 15분 안에 돌아오면 덮개 없이 연다.
- 기기 암호조차 없으면 "기기 암호를 설정해야 기록이 보호됩니다" 안내를 띄우고 기능은 쓰게 둔다.

### 목록
- 사건 시각이 최근인 것이 위. `approx`는 날짜 정보가 없으면 기록 시각으로 정렬한다.
- 행: 사건 시각 · 구분 배지 · 상태(`이관`·`마무리`일 때만 표시) · 제목 · 관련인 이름 · 첨부 수 · `수정 N회`.
- 위쪽 `사람` 버튼 → 한 사람을 고르면 그 사람이 **현재 판**의 관련인에 든 기록만.
- 구분 필터(`전체 / 생활지도 / 교육활동 침해`).
- 상단 메뉴: `삭제한 기록`. 오른쪽 아래 `+`. (`명단 관리`는 2026-10-04에 뺐다 — 명단은 저장할 때 자동으로 채워진다.)
- 빈 화면: 상태 한 줄 + 범위 안내 한 줄.

### 기록 쓰기 (전체 화면, 새 기록·고치기 공용)
- 구분 세그먼트 · 진행 상태 · 사건 시각(정확/날짜만/대략) · 제목 · 장소 · 관련인 · 경과 · 들은 말 · 판단·조치 · 첨부(녹음하기 / 녹음 파일 가져오기 / 사진 가져오기).
- **관련인 칸은 바로 쓰는 입력칸이다**(2026-10-04 — 예전 `+ 사람 추가` 시트를 대신한다). 쉼표(`,`·`，`)를 치면
  앞의 이름이 칩이 되고, 한 번에 붙여 넣은 `김하늘, 이도윤, 박서준`은 셋 다 칩이 된다. 엔터(완료)도 남은 글을 칩으로
  만든다. 빈 이름·중복은 무시, 칩의 ×로 뺀다. **칩이 안 된 글도 저장할 때 관련인으로 넣는다**(이름 하나만 치고 바로
  저장하는 일이 흔하다). 칸 힌트: *이름을 쉼표로 구분해 여러 명 쓸 수 있어요*.
- 이름을 치는 동안 아래에 **추천**(명단에서 친 글을 포함하는 이름, 이미 넣은 사람 제외, 5개까지). 누르면 칩, 길게
  누르면 확인 뒤 추천에서 지운다.
- 관련인 칸 아래 안내: *가해·피해를 나누어 적지 않아요. 판단이 나오기 전의 기록이 결론처럼 읽힐 수 있어서입니다. 필요하면 경과에 사실대로 적어 주세요.*
- 들은 말 칸 아래: *누가 무엇이라고 말했는지 들은 그대로 적어 주세요.*
- 판단·조치 칸 아래: *어떻게 지도했는지, 보호자 연락·학교 보고·이관을 언제 했는지 적어 주세요.*
- **녹음이 끝났는데 기록이 아직 저장 전이면 자동으로 판 1을 저장한다** — 녹음 뒤 실수로 나가도 사라지지 않게. 사진 가져오기도 같다.
- 저장하지 않은 글이 있는데 나가려 하면 확인을 묻는다(`ConfirmDialog`).

## 잠금 (구현의 급소)

- 잠금 상태는 메모리 provider 하나(기본 잠김, autoDispose 아님 — 게이트보다 오래 산다). 저장하지 않는다.
- **15분 규칙**: 한 번 풀면 탭을 옮겨도 다시 묻지 않는다. **지도 기록을 떠난 지 15분이 지나면** 돌아올 때 잠근다.
  - 떠남 = 다른 탭으로 옮김 · 앱이 `hidden`/`paused`. 떠난 시각은 처음 것만 남는다.
  - `inactive`(알림 센터·제어 센터·Face ID 창·전화 배너)로는 잠그지도, 떠난 시각을 찍지도 않는다.
  - 15분은 설정 없이 상수 하나(`guidanceRelockAfter`).
  - 바뀐 이유(사용자 결정 2026-10-03): 처음 규칙(탭을 옮기거나 앱을 떠나면 잠김)은 "매번 Face ID를 묻는 것이 너무 심하다"는 신고를 받았다. 비밀번호 앱과 비교해(1Password 기본 즉시·선택 1분~1시간, Bitwarden 모바일 기본 15분, Apple 메모 몇 분) 15분으로 정했다.
- **가림 면**: 풀린 상태에서 `inactive`가 오면 문구 없는 불투명 면(배경색 + 자물쇠, iOS 가림막과 같은 모양)으로 화면을 가린다. 만료는 돌아온 `resumed`에서야 아는데 그때 덮개를 올리면 그려지기 전 몇 프레임 기록이 보이고, `hidden`/`paused`에서는 프레임이 그려지지 않아 거기서는 가릴 수 없기 때문이다. 잠금 상태와 떠난 시각은 건드리지 않는다 — 15분 안에 돌아오면 면만 걷고 묻지 않는다. 부작용: Android 알림창을 내릴 때(iOS 제어 센터도)도 화면이 가려진다.
- 기기 시계가 뒤로 갔으면(떠난 시각보다 지금이 이르면) 만료로 친다 — 시각을 돌려 재잠금을 피하지 못한다.
- **알고 두는 한계**: iOS에서 `paused` 없이 오래 `inactive`에만 머무는 경우(전화 UI 등)와, 지도 기록을 앞에 띄운 채 기기 자동 잠금이 꺼져 있는 경우에는 떠남이 찍히지 않아 다시 잠기지 않는다.
- 인증 창을 취소한 뒤 돌아와도 다시 묻지 않는다 — 복귀에서 묻는 것은 풀려 있다가 만료된 경우뿐이다(무한 반복 방지).
- 시스템 창(파일·사진 선택·마이크 권한) 중의 백그라운드도 떠남으로 찍히고 15분 규칙이 판단한다. 시스템 창 가드는 녹음 화면(시스템 창의 `inactive`에 녹음을 멈추지 않기)에만 쓴다.
- **덮개는 화면을 덮기만 한다.** 아래 화면을 dispose하지 않으므로 잠금을 풀면 쓰던 글이 그대로다.
- 녹음 중 앱을 떠나면: 녹음 저장(잠금은 15분 규칙을 따른다).
- 앱 전환 화면:
  - Android: 이 탭이 보이는 동안 `FLAG_SECURE`(스크린샷도 막힌다).
  - iOS: 이 탭이 보이는 동안 비활성 순간 네이티브(SceneDelegate) 가림막을 올린다(Flutter 덮개는 한 프레임 늦다). 인증을 묻지 않아도 앱 전환기에서 내용이 가려진다.
- 다른 화면에서 이 기록이 보이는 경로를 만들지 않는다(캘린더·오늘 탭·공용 휴지통·검색 없음).

## 다른 기능과의 분리

- CSV 내보내기·알림·Google/기기 캘린더·단축어 조회·공용 휴지통은 `guidance_*`를 읽지 않는다 → 가드가 그 파일들의 소스에 테이블 이름이 나오면 실패.
- **전체 데이터 초기화**는 지도 기록도 지운다(기능 관리 규칙 8). 확인 창에 *지도 기록 N건과 첨부 N개도 지워집니다*를 따로 적는다. 첨부 폴더도 비운다.

## 개인정보처리방침·스토어

- §2 "마이크 … 정보를 수집하지 않습니다" 문장을 고친다. 지도 기록의 항목(이름·기록 내용·녹음·사진)과 저장 위치(기기 안), 서버 전송 없음, 마이크·사진 접근은 사용자가 녹음·첨부할 때만.
- §5-4 백업: Android에서는 첨부가 백업에 포함되지 않음, iOS는 포함.
- App Store 개인정보 라벨: 기기 밖으로 나가지 않으므로 "수집 안 함" 유지. Play 데이터 보안: 같은 이유로 유지, 권한 목록에 마이크 추가 — 제출 때 재확인.
- ⚠️ 미확인: 교사 개인 기기에 학생 명단을 저장하는 것에 대한 시도교육청 지침. 서버 전송이 없어 위험은 낮다고 보지만 확인된 사실이 아니다.
