# 포스트잇 탭 — 설계

날짜: 2026-10-03 · 선행: `2026-10-02-feature-modules-design.md`(기능 모듈), `2026-10-03-module-settings-design.md`(기능별 설정)
시안: Claude 디자인 캔버스 https://claude.ai/artifact/PzqaWavawwdNcNsSTptBPC — 사용자 선택 **A(보드형) + C + E**

## 배경과 목표

사용자 요청(2026-10-03): 시간표는 생각할 부분이 있어 미루고, 먼저 **포스트잇 탭** —
"간단한 메모하는 장소 느낌으로 하고 캘린더에도 포스트잇이 연결되었으면 좋겠어".

- 일정으로 정식 등록하기 애매한 것을 **붙여 두는 자리**다.
- 날짜를 붙이면 **그날 캘린더에 보인다**(시안 C).
- 메모를 나중에 **정식 일정(업무·행사)으로 바꿀 수 있다**(시안 E).
- 등록부의 **첫 탭형 선택 기능**이다 — 기능 관리에서 켜야 탭이 생긴다.

## 결정 (사용자 선택, 2026-10-03)

| 질문 | 결정 |
|---|---|
| 탭 모양 | **A 보드형** — 쪽지 색 카드 2열 격자 |
| 캘린더 연결 | **C** 날짜를 붙이면 그날 캘린더에 보인다 + **E** 일정으로 바꾼다. D(캘린더에서 바로 붙이기)는 이번 범위 밖 |
| 다 쓴 포스트잇 | **떼면 휴지통**(30일 보관 후 자동 삭제 — 다른 삭제와 같은 규칙) |
| 일정으로 바꾼 뒤 | **자동으로 뗀다**(휴지통으로) — 같은 날 일정과 쪽지가 겹쳐 보이지 않게 |
| 오늘 탭 | **보이지 않는다** — 오늘 탭은 업무·도장·결산 링만 다룬다 |
| 쪽지 순서 | **꾹 눌러 끌어서 바꾼다** — 순서는 저장된다 |
| 순서 바꾸기 구현 | **직접 만든다**(Flutter 내장 `LongPressDraggable` + `DragTarget`) — 새 패키지 없음 |
| 저장 | **새 DB 테이블 `memos`**(v8 → v9). 설정 저장소(JSON)·캘린더 이벤트 종류 추가는 기각 |

기각한 저장 방식:
- **shared_preferences JSON** — 휴지통(soft-delete)·날짜 조회·초기화를 따로 만들어야 한다.
- **`calendar_events`에 `memo` 종류** — 내보내기·알림·Google/기기 저장·오늘 탭·스와이프가 전부
  이 행을 걸러야 한다. 편집 시트의 `copyWith` 함정처럼, 한 곳이라도 빠뜨리면 쪽지가 일정으로 새어 나간다.

## 데이터

### `memos` 테이블 (DB v9)

| 칸 | 형 | 뜻 |
|---|---|---|
| `id` | INTEGER PK | |
| `text` | TEXT NOT NULL | 메모 글 |
| `color` | TEXT NOT NULL DEFAULT `'yellow'` | `yellow`·`green`·`blue`·`pink`. 모르는 값은 노랑으로 폴백 |
| `memo_date` | TEXT NULL | `YYYY-MM-DD`. 있으면 그날 캘린더에 보인다 |
| `sort_order` | INTEGER NOT NULL | 보드 순서. **작을수록 앞**. 새 쪽지는 (현재 최소값 − 1) |
| `created_at`, `updated_at` | TEXT | ISO |
| `deleted_at` | TEXT NULL | NULL = 활성, ISO = 휴지통 |

- 마이그레이션 `v8→v9`는 `CREATE TABLE memos`뿐이다. 기존 테이블은 건드리지 않는다.
- 활성 조회는 `WHERE deleted_at IS NULL` 필수(리포 규칙). 보드는 `ORDER BY sort_order`,
  캘린더는 `memo_date BETWEEN` 범위 조회.
- `color`·`memo_date`는 모델에서 enum·`DateTime?`으로 다룬다(Freezed). 저장값 `'yellow'` 등은
  **저장값이라 바꾸지 않는다**(기능 id와 같은 규칙).

## 화면

### 포스트잇 탭 (보드형, 시안 A)

```
            MEMO
           포스트잇
[떠오른 것을 바로 적어 두세요________] [+]
┌───────────┐ ┌───────────┐
│ 학부모 상담 │ │ 공개수업   │
│ 때 …      │ │ 지도안 …   │
│ 10.2      │ │ 📅10.17(금)│
└───────────┘ └───────────┘
┌───────────┐ ┌───────────┐ …
```

- 빠른 입력 칸에 적고 `+`(또는 키보드 완료)를 누르면 **노랑 쪽지가 맨 앞에** 붙는다. 빈 글은 붙지 않는다.
- 2열 격자. 쪽지는 글(최대 5줄, 넘치면 말줄임) + 아래에 날짜 표시(날짜 있음: 파란 달력 아이콘 +
  `10.17 (금)` / 없음: 적은 날 `10.2` 옅은 글씨).
- **짧게 누르면 쪽지 시트**, **꾹 누르면 들려서 끌기** — 놓은 자리로 순서가 바뀌고 저장된다.
- 쪽지가 없으면 빈 상태 두 줄: 상태 + 다음 행동(리포의 빈 상태 규칙).
- 쪽지 색 네 가지는 네이비 글자가 4.5:1 이상인 옅은 색이다. 다크 테마는 같은 색 계열을 어둡게 맞춰
  대비를 지킨다(구현 때 대비 가드로 고정).

### 쪽지 시트 (시안 E)

- 글 편집, 쪽지 색 네 개(선택 표시는 **체크 아이콘 + 테두리** — 색만으로 두지 않는다), 날짜 줄(붙이기·바꾸기·빼기).
- **일정으로 등록**: `업무`/`행사` 세그먼트 + 버튼. 날짜는 쪽지 날짜, 없으면 오늘이 기본이고 시트에서 바꿀 수 있다.
  등록하면 **확정된 캘린더 일정**이 생기고(손으로 넣은 일정과 같은 경로 — 원본 `schedules` 행 없음)
  쪽지는 **휴지통으로 간다.** 스낵바로 알린다.
- **떼기**: 쪽지를 휴지통으로 보낸다. 확인 창은 없다(휴지통에서 되살릴 수 있다).
- 키보드 여백은 두 편집 시트와 같은 `math.max(0, viewInsets.bottom)` 규칙을 따른다.

### 캘린더 (시안 C)

- 그날 목록에 날짜 붙은 쪽지가 **쪽지 색 카드**로 보인다(일정은 흰 카드). 위치는 그날 일정들 **뒤**.
- 격자 날짜 셀에 일정 점과 구별되는 **작은 네모 점** 하나(쪽지가 몇 개든 하나).
- 쪽지 카드를 누르면 같은 쪽지 시트가 열린다. **`Dismissible`이 아니다** — 스와이프(외부 저장·완료)는 일정의 동작이다.
- 일정이 없고 쪽지만 있는 날도 그날 섹션이 생겨야 한다(공휴일 행의 `mergeHolidayKeys`와 같은 문제).
- **포스트잇 기능이 꺼져 있으면 캘린더에도 쪽지가 보이지 않는다.** 데이터는 남는다.

## 기능 모듈과의 관계

- 등록부 항목: `id: 'memo'`(저장값 — 바꾸지 않는다), 이름 `포스트잇`, 탭형, 라우트 `/memo`.
  기능 관리에서 켜면 설정 앞에 붙는다. **`settingsRoute` 없음**(상세 설정이 없다).
- 탭형 라우트는 설치 여부와 무관하게 라우터에 항상 등록한다(등록부 가드).
- **시간표 때 하기로 했던 정리를 이번에 한다**(첫 탭형 기능이라 필요해진다):
  - `defaultTabs`·고정 탭 상수를 기능을 모르는 파일로 분리 — 지금 `MainShell`이 등록부를 거쳐
    `features/bus`에 간접적으로 닿는다.
  - 기능 관리의 드래그를 `onReorder`(deprecated, `ignore` 주석) → `onReorderItem`으로 옮긴다.
  - 탭형 가드(라우트 등록·6탭 폭·상한)가 처음으로 실제 탭형 기능을 검사한다.

## 휴지통 · 초기화

- **휴지통**: 뗀 쪽지가 `포스트잇` 줄로 보이고 되살리기·영구 삭제가 된다. `purgeOlderThan`(30일)에 `memos`도 든다.
  `TrashSnapshot`에 쪽지 목록이 더해진다.
- **전체 데이터 초기화**: `memos`도 지운다(설정 메뉴 규칙 8 — 기능의 데이터는 지우고 설정은 남긴다).
  확인 창 문구에 포스트잇을 넣는다.
  - 규칙 8의 "등록부가 초기화 방법을 선언"은 **이번에는 하지 않는다** — 데이터를 가진 기능이 하나뿐이라
    `resetAllData`에 테이블 하나를 더하는 편이 단순하다. 둘째 기능이 생길 때 등록부로 올린다.

## 순서 바꾸기 (직접 구현)

- 쪽지마다 `LongPressDraggable`(끌리는 모습 = 살짝 커진 쪽지) + 자리마다 `DragTarget`.
  놓으면 순서 목록에서 옮기고 바뀐 쪽지들의 `sort_order`를 한 트랜잭션으로 다시 쓴다.
- 순서 계산은 **순수 함수**(옮긴 뒤 목록 → 새 `sort_order`)로 빼서 유닛 테스트로 고정한다.
- 끄는 중에는 탭(쪽지 시트 열기)이 일어나지 않는다.

## 테스트

- **DB**: v8→v9 마이그레이션(기존 데이터 유지 + 빈 `memos`), 활성 조회의 `deleted_at` 필터, 범위 조회, 순서.
- **저장소**: 붙이기(맨 앞) · 고치기 · 떼기(휴지통) · 되살리기 · 영구 삭제 · 30일 정리 · 초기화 포함.
- **일정으로 바꾸기**: 일정이 생기고(종류·날짜 승계) 쪽지는 휴지통 · 날짜 없는 쪽지는 오늘(또는 고른 날).
- **순서 순수 함수**: 앞→뒤, 뒤→앞, 제자리.
- **위젯**: 빠른 입력(빈 글 거부) · 짧게 누르면 시트 · 끌어서 순서 변경 · 쪽지 색 선택 표시(체크) ·
  320/390/430pt 넘침 · 빈 상태.
- **캘린더**: 날짜 붙은 쪽지가 그날 목록 뒤에 · 쪽지만 있는 날도 섹션 · 격자 네모 점 · `Dismissible` 아님 ·
  **기능이 꺼지면 안 보임**.
- **등록부 가드**: `memo` 라우트가 라우터에 있음, 배포 id 목록에 `memo` 추가, 6탭 폭(실제 기능으로).
- **대비 가드**: 쪽지 색 네 개 × 두 테마에서 글자 4.5:1.
- **런타임**: 시뮬레이터 시나리오(켜기 → 붙이기 → 날짜 → 캘린더에 보임 → 일정으로 등록 → 쪽지 휴지통 →
  순서 끌기 → 끄면 캘린더에서 사라짐), 볼 장면만 `flutter drive`로 캡처.

## 건드리지 않는 것

- 오늘 탭, 알림, CSV 내보내기, Google/기기 캘린더 저장, 아이폰 단축어.
- 캘린더에서 바로 붙이기(D) — 다음에 필요하면 같은 쪽지 시트를 캘린더에서 여는 것으로 붙일 수 있다.
