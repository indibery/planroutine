# 지도 기록 — 쓰기는 바로, 열어 볼 때 잠금 (설계)

2026-11-03. 사용자 요청과 대화로 정했다. 구현 계획은 이 문서를 바탕으로 따로 쓴다.

## 왜

실기기 피드백: **"상담하면서 바로 녹음 시작하려는데 Face ID부터 떴어."**

지도 기록은 상담·사건이 벌어지는 **그 순간** 쓰는 기능이다. 지금은 탭에 들어가는 순간 잠금 덮개와 Face ID가 뜬다
(`GuidanceLockGate`가 탭 전체를 감싼다). 잠금을 둔 목적은 **이미 남긴 기록을 남이 보지 못하게** 하는 것이지,
새로 쓰는 것을 막는 것이 아니다. 그래서 잠금을 "탭에 들어갈 때"에서 "예전 기록을 열어 볼 때"로 옮긴다.

## 목표

- 지도 기록 탭에 들어가면 인증 없이 **목록이 바로** 보인다.
- `녹음으로 새 기록`·`+ 새 기록`은 인증 없이 바로 된다. 녹음 → 멈춤 → 저장까지 한 번도 묻지 않는다.
- 목록에서 **예전 기록을 열 때** 처음 한 번 Face ID를 묻는다. 풀면 지금의 15분 규칙(떠난 지 15분까지 다시 묻지 않음)을 그대로 따른다.
- 잠긴 동안 목록은 기록이 있다는 것과 언제·무슨 구분인지만 보여 주고, **제목과 관련인 이름은 가린다**(사용자 결정).

## 목표가 아닌 것

- 15분 규칙·가림 면(`_veil`)·FLAG_SECURE·iOS 앱 전환기 가림막의 규칙은 바꾸지 않는다.
- 잠금을 아예 끄는 설정은 만들지 않는다.
- 다른 탭(캘린더·오늘·휴지통 등)과의 분리 규칙은 그대로다.

## 실패로 치는 것 (anti-goals)

- 잠긴 상태에서 **학생 이름**이 어디서든 보이는 것. 제목·관련인 줄·사람 필터·이름 추천·필터 칩 라벨 어느 곳이든.
- 새 기록을 쓰는 도중(녹음 포함) Face ID가 끼어드는 것.
- 잠긴 상태에서 예전 기록의 내용(사실·발언·조치·첨부·이력·전사)에 인증 없이 닿는 길이 남는 것. 딥링크(끊긴 녹음 되살리기)도 포함.

## 화면별 동작

### 잠금이 필요 없는 곳 (열린 곳)
- 목록 `/guidance`
- 새 기록 `/guidance/new`(`?record=1` 포함)와 그 위에 뜨는 녹음 화면

### 잠금이 필요한 곳
- 기록 보기 `/guidance/record/:id`와 그 아래 전부(편집·이력·전사)
- 삭제한 기록 `/guidance/trash`

### 잠긴 목록
- 한 줄에 보이는 것: 사건 시각, 구분 배지(생활지도/교육활동 침해), 상태 배지, 첨부 수, 수정 횟수.
- 사건 시각이 `대략`(직접 쓴 글)인 기록은 그 글을 보이지 않는다 — 자유 입력이라 이름이 들어갈 수 있다(`formatOccurred`가 `occurredText`를 그대로 낸다). 날짜가 있으면 날짜만, 없으면 `시각 대략` 같은 자리표시. **내 판단**(실패 조건 "이름이 어디서든 보이면"에서 바로 따라 나온다).
- 가리는 것: 제목, 관련인 이름 줄, **줄의 스크린리더 이름**(`guidanceRecordSemanticsLabel`이 제목·이름을 넣는다 — 글자만 가리면 VoiceOver·자동화 도구가 이름을 읽는다). 제목 자리에 `잠긴 기록`(문구는 `GuidanceStrings`에 새로) 같은 자리표시를 둔다. 정확한 모양(문구 vs 흐린 막대)은 구현자 판단.
- `사람: …` 필터 칩은 숨긴다. 풀린 동안 사람을 골라 둔 채 잠기면 그 필터는 **적용하지 않는다**(골라 둔 사람만 남은 목록 자체가 그 사람을 드러낸다). 다시 풀리면 골라 둔 필터가 돌아오는지는 구현자 판단(내 판단: 돌아오지 않고 `전체`로 초기화하는 쪽이 단순하다).
- 구분 필터(전체/생활지도/교육활동 침해)는 그대로 쓴다.
- 잠긴 줄을 누르면 **그 자리에서** 인증하고, 성공하면 기록 보기로 간다. 취소·실패면 목록에 머문다(덮개 화면으로 밀어 넣지 않는다).
- `삭제한 기록` 버튼도 같다 — 누르면 인증, 성공하면 들어간다.
- 기기 암호가 없으면(`AuthOutcome.noCredentials`) 지금 덮개의 `잠금 없이 열기`와 같은 효과를 낸다. 어디서 그 안내를 보여 줄지는 구현자 판단(내 판단: 줄을 눌렀을 때 짧은 확인 창).

### 새 기록 화면
- 관련인 칸의 **이름 추천을 끈다**(잠긴 동안). 추천은 예전에 저장한 학생 이름 명단이다. 직접 쓰는 칩 입력은 그대로 된다.
- 저장하면 지금처럼 목록으로 돌아간다(`Navigator.pop`). 잠긴 상태면 방금 쓴 기록도 목록에서 가려진다 — 맞는 동작이다.

### 잠금이 필요한 곳의 덮개
- 지금의 덮개 + 자동 인증을 그대로 쓴다. 다만 줄 누르기·`삭제한 기록`은 먼저 인증하므로, 덮개가 실제로 뜨는 것은
  **딥링크**(끊긴 녹음 되살리기 `app.dart`의 `go(guidanceEdit(id))` — **이때도 묻는다**, 사용자 결정 2026-11-03: 드문 경우라 범위를 키우지 않는다)와 **잠금이 필요한 화면에 있는 동안 15분이 만료된 뒤 돌아온 경우**다.
- 덮개 위에서 취소하면 그 화면에 갇히지 않아야 한다 — 탭바는 덮개 밖이라 다른 탭으로 갈 수 있지만, 같은 탭의 목록으로 돌아가는
  길(뒤로)이 덮개 안에 있어야 한다.

### 복귀(`resumed`)
- 15분이 만료됐을 때 **잠금이 필요한 화면**에 있었으면 지금처럼 덮개 + 인증.
- **열린 화면**(목록·새 기록)에 있었으면 묻지 않고 잠금 상태로만 돌린다. 목록은 가려지고, 쓰던 새 기록은 그대로 이어 쓸 수 있다.

## 정해진 구현 방향 (내 판단)

- **게이트를 지우지 않고 경로를 알게 한다.** 중첩 셸 builder가 `state.uri.path`로 "잠금 필요 여부"를 정해
  `GuidanceLockGate(requiresUnlock: …)`로 넘긴다. 기본값은 `true` — 그래야 기존 게이트 테스트 23건이 "잠금이 필요한 화면"의
  동작으로 그대로 통과한다. 경로 판정은 순수 함수 하나로 둔다(`/guidance`·`/guidance/new`만 열림, 그 밖은 잠김 — **모르는 경로는 잠김**).
- 잠금 상태의 주인은 지금처럼 `guidanceUnlockProvider`(`GuidanceUnlock`) 하나다. 목록·이름 추천은 그것을 **watch**해 가림을 정한다 —
  `GuidanceUnlock`은 알림을 주지 않는 평범한 객체다(검토에서 확인) — 가림을 다시 그리게 할 신호를 더한다.
- **경로 판정 위치는 실측으로 정한다.** 목록에서의 이동은 모두 `context.push`다. go_router(현재 버전)에서 push한 하위 경로가
  중첩 셸 builder의 `state.uri`에 들어오는지, pop하면 `/guidance`로 돌아와 builder가 다시 불리는지 **먼저 작은 테스트로 확인**한다.
  안 되면 잠긴 화면 각각을 같은 게이트로 감싸는 쪽으로 옮긴다(구현자 판단).
- 게이트는 `requiresUnlock`이 `false → true`로 바뀌는 순간에도 자동 인증을 건다(지금은 `initState`에서만).
- "누르면 먼저 인증" 동작은 게이트의 `_authenticate`와 같은 규칙(중복 방지 `_authing`, 예외 = 실패)을 쓰는 함수 하나로 모은다.
  게이트와 목록이 따로 구현하면 규칙이 갈라진다.
- `SecureWindow`(FLAG_SECURE, iOS 가림막 플래그)는 지금처럼 **탭 전체**에서 켠다 — 새 기록도 학생 이야기다.

## 가드 (테스트)

- 경로 판정: 열린 둘 · 잠긴 다섯(보기·편집·이력·전사·삭제한 기록) · 모르는 경로는 잠김.
- 잠긴 목록에 제목·관련인 이름·사람 필터 칩이 없다(픽스처 기록에 학생 이름을 넣고 `find.textContaining(이름)` 0건 **+ 시맨틱스 트리에도 0건**). 정밀도 `대략` 기록의 글에 이름을 넣은 픽스처도 포함.
- 잠긴 상태에서 새 기록 화면 이름 추천이 뜨지 않는다(명단에 이름이 있어도).
- 잠긴 줄 누르기: 성공 → 기록 보기, 취소 → 목록에 머묾, 인증 1회.
- 열린 화면에서 15분 만료 후 복귀: 인증 요청 0회, 목록이 가려짐.
- 잠긴 상태에서 딥링크로 편집 화면 → 덮개 + 인증.
- 기존 게이트 테스트 23건은 지우지 않는다(`requiresUnlock` 기본값으로 통과).
