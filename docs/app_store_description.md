# App Store 설명 (스토어 공개 문구)

App Store Connect → 공직플랜 → 버전 → **설명(Description)** 에 붙여넣는 글.
사용자에게 보이는 유일한 소개문이라, 없는 기능을 적으면 실사용자 불만·심사 반려로 이어진다.

**기준 버전: 1.2.0**

---

```text
공직플랜은 교직원의 반복되는 연간 업무 사이클을 손쉽게 관리할 수 있는 일정 관리 앱입니다.

■ 주요 기능

· 오늘 할 일
앱을 열면 오늘 처리할 일정만 모아 보여줍니다. 동그라미를 누르면 바로 완료 처리되고,
완료 도장이 찍히며 위쪽 진행 링이 채워집니다. 기한이 지난 일정은 최근 일주일까지 따로
모아 접어두어, 오늘 할 일에 집중할 수 있습니다.
도장 모양은 완료·결재·좋아요 중에서 고를 수 있습니다.

· 작년 일정 가져오기
에듀파인 생산문서등록대장 CSV를 업로드해 작년 업무를 그대로 불러옵니다.
카카오톡·메일·AirDrop 등 어느 경로로 받은 파일이든 공유시트에서 "공직플랜"을 선택하면
즉시 불러옵니다. 종이 행사표를 사진으로 찍어 AI로 변환해 등록하는 방법도 안내합니다.

· 검토 후 확정
불러온 일정을 검토 탭에서 슬라이드로 확정하거나 삭제합니다. 카테고리별로 걸러 볼 수
있고, "대기 N건 확정" 버튼으로 한 번에 올해 일정으로 등록할 수도 있습니다.

· 자체 캘린더
앱 내에서 직접 이벤트를 만들고 편집할 수 있습니다. 설명 메모, 중요 표시(★),
대한민국 공휴일 표시를 지원하며, 주말이 한눈에 구분되도록 정리했습니다.
작년 자료에서 넘어온 "2025학년도…" 같은 제목은 배지를 눌러 올해 연도로 바꿀 수 있습니다.

· 로컬 알림
매주 월요일 아침에 그 주 일정을 한 번에 알려주고, 일정 당일 아침에 다시 알려줍니다.
알림 시각은 사용자가 직접 조정할 수 있습니다(기본 오전 8시).

· 캘린더 연동 (선택)
원하면 확정한 일정을 Google 캘린더나 iPhone 기본 캘린더로 보낼 수 있습니다.
기본은 꺼져 있고, 설정에서 직접 선택할 때만 동작합니다.

· 휴지통 (30일 보관)
삭제된 일정·이벤트는 30일간 휴지통에 보관되며 언제든 복원할 수 있습니다.

· CSV 내보내기
확정된 일정을 UTF-8 CSV로 내보내 Excel·다른 앱과 공유할 수 있습니다.
다시 가져올 때는 확정 상태 그대로 복원됩니다.

· 밝게·어둡게 화면
기기 설정을 따르거나, 밝은 화면과 어두운 화면을 직접 고를 수 있습니다.

■ 개인정보 보호

· 모든 데이터는 사용자의 iPhone 내부에만 저장됩니다.
· 회원가입이나 로그인이 없습니다. 개발자가 사용자의 업무 일정에 접근하거나 수집하지
  않습니다.
· 앱이 자체 서버로 데이터를 보내는 일은 없습니다. 위의 캘린더 연동을 직접 켰을 때만,
  사용자가 고른 일정이 선택한 캘린더로 전송됩니다.
· 앱을 삭제하면 모든 데이터가 즉시 삭제됩니다.

■ 문의

bery97@gmail.com
```

## 1.2.0에서 고친 것 (코드로 확인)

| 낡은 서술 | 실제 |
|---|---|
| 알림 "월초, 1주 전, 1일 전" | **매주 월요일 이번 주 종합 + 당일 아침** (월초는 제거됨) |
| "이벤트 색상 지원" | **색상 피커 없음.** 이벤트 색은 공통 액센트로 통일됐다 |
| "종일 이벤트 지원" | 모든 이벤트가 종일 고정(`isAllDay: true`) — 선택 기능이 아니라 오해를 준다 |
| "일정 탭" | 탭 이름은 **검토** |
| "전체 확정" | 실제 라벨은 **"대기 N건 확정"** (스코프·건수 동적) |
| 오늘 탭 없음 | **1.2.0의 핵심이자 첫 화면** — 맨 위로 |
| "외부 서버로 전송하지 않습니다" | 캘린더 연동을 켜면 전송이 있다 → 두 층으로 나눠 서술 |

## 고칠 때 주의

**앱에 없는 기능을 적지 않는다.** 특히 색상·반복 일정·팀 공유는 지금 없다.
아래가 바뀌면 이 설명도 함께 고친다.

- 알림 구성 (`notification_strings.dart` / `notification_rules.dart`)
- `app_features.dart`의 `googleCalendarEnabled`
- 탭 구성·이름 (`main_shell.dart`)
- 확정 pill 라벨 (`schedule_strings.dart`)
- 도장 종류 (`stamp_settings.dart`의 `SealStyle`)
