# App Store 심사 노트 (App Review Information → Notes)

App Store Connect의 **앱 심사 정보 → 메모**에 붙여넣는 글. 기능이 바뀌면 여기를 먼저 고친다.
심사관에게만 보이고 스토어에는 노출되지 않는다. `release` 레인이 자동 입력한다.

**사실과 어긋나면 반려 사유가 된다** — 알림 구성·외부 전송 여부·기능 플래그 상태를 바꿀 때
반드시 함께 갱신할 것.

⚠️ **아래 ```text 블록이 곧 ASC에 들어가는 내용이다.** `release` 레인이 이 블록을 파싱해
App Review Information의 메모에 자동 반영한다. 블록 밖의 설명글은 반영되지 않는다.
블록 표시를 ```text 그대로 유지할 것 — 형식이 깨지면 release가 중단된다.

## 현재 버전 (1.2.0)

```text
공직플랜은 대한민국 교직원 및 공무원의 업무 일정 관리를 돕는 로컬 앱입니다.

■ 기능 개요
- 오늘 탭: 오늘 처리할 일정만 모아 보고, 체크 한 번으로 완료 처리(완료 도장 + 진행 링)
- 에듀파인(대한민국 학교 행정 시스템)에서 받은 CSV를 가져와 올해 일정으로 검토/확정
- 자체 캘린더에 이벤트 생성/편집, 휴지통(30일 보관 후 자동 삭제)
- iOS 로컬 알림: 매주 월요일 '이번 주' 종합 + 이벤트 당일 아침 (기본 08:00, 시각 변경 가능)
- 확정 일정을 CSV로 내보내기
- 화면 테마(시스템/밝게/어둡게)

■ 데이터 처리
- 모든 데이터는 기기 내부 SQLite에만 저장됩니다.
- 사용자 인증·로그인이 필요 없습니다. 계정 개념이 없습니다.
- 앱이 자체 서버로 데이터를 보내는 경로는 없습니다. 개발자는 사용자 데이터에
  접근할 수 없습니다.
- 외부로 데이터가 나가는 경우는 아래 두 가지이며, 모두 사용자가 직접 켜거나
  실행할 때만 동작합니다(기본 꺼짐).

■ Google 캘린더 / 기기 캘린더 연동 (선택)
- 설정 → 캘린더 연동에서 '사용 안 함'(기본) / 'Google 캘린더' / '기기 캘린더' 중 선택합니다.
- 'Google 캘린더'를 선택하고 로그인하면, 사용자가 캘린더 목록에서 오른쪽으로 스와이프한
  이벤트만 Google Calendar API로 저장됩니다. 단방향(앱 → Google)이며 읽어오지 않습니다.
- 사용 scope는 auth/calendar.events 하나입니다. OAuth 심사(Branding·Data access)를
  통과한 상태입니다.
- '기기 캘린더'는 iOS 캘린더 권한으로 기기 내 캘린더에만 씁니다(외부 전송 없음).

■ AI 기능 (선택, 앱이 네트워크를 쓰지 않음)
- 행사표 사진 → 일정 변환: 앱이 '변환 프롬프트'를 클립보드에 복사해 줍니다. 사용자가
  외부 AI 앱에서 사진과 함께 사용한 뒤, 응답(JSON)을 복사해 앱에 붙여넣으면 앱이 파싱해
  일정으로 등록합니다. 앱이 사진이나 데이터를 어디에도 전송하지 않습니다.
- 'AI로 보내기'(기본 꺼짐): 켜면 이벤트 편집에 버튼이 생기고, 누르면 iOS 공유시트로
  일정 텍스트를 사용자가 고른 앱에 넘깁니다. 전송 대상은 사용자가 그 자리에서 선택합니다.

■ 테스트 방법
1. 앱을 열면 '오늘' 탭이 나옵니다. 일정이 없으면 오른쪽 아래 + 버튼으로 하나 만들어
   동그라미를 눌러보시면 완료 처리(도장·진행 링)를 확인할 수 있습니다.
2. CSV 가져오기: 설정 탭 → '일정 가져오기' → '파일 선택'
3. 테스트용 샘플 CSV는 아래 링크에서 받을 수 있습니다. 가상 학교·가명으로 만든
   더미 데이터이며 개인정보가 없습니다.
   https://github.com/indibery/planroutine/blob/main/data/sample/2025_생산문서등록대장.csv
4. 또는 카카오톡·AirDrop·이메일로 받은 CSV를 탭하고 공유시트에서 '공직플랜'을 선택하면
   앱이 열리며 파일이 자동으로 로드됩니다.
5. Google 연동을 확인하시려면 설정 → 캘린더 연동 → 'Google 캘린더' 선택 후 로그인하고,
   캘린더 탭에서 이벤트를 오른쪽으로 스와이프해 주세요.

감사합니다.
```

## 갱신 이력

- **1.2.0 (2026-07-25)**: 오늘 탭 추가. 알림 설명을 실제 구성으로 교정
  (월초·1주 전·1일 전 → **이번 주(월요일) + 당일 아침**). Google 캘린더가 플래그 OFF라던
  서술을 삭제 — OAuth 심사를 통과해 **기본 제공(선택 사용)** 상태다. 기기 캘린더 옵션과
  AI 기능 2종(클립보드 변환 / 공유시트 보내기)을 명시. "외부 전송이 전혀 없다"를
  "앱 자체 서버로 보내는 경로가 없다 + 사용자가 켠 연동만 외부로 나간다"로 정정 —
  Google 연동이 켜지면 실제로 외부 전송이 있으므로 이전 문구는 사실과 달랐다.
