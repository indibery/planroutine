# 공직플랜 검증 지도

사용자에게 보이는 동작을 검증하는 원본이다. 조작하기 전에 이 목차를 읽고, 맞는 기능 파일을 절차로 쓴다.
도구 사용법은 `driving-ios-simulator` 스킬, 실행·점검·증거·정리는 상위 `SKILL.md`를 따른다.

> ⚠️ **실행 증명 전(2026-11-03)**: 이 지도는 소스의 문자열·시맨틱스 라벨로 썼다. 처음 만든 날 시뮬레이터가
> 설치·실행·캡처에서 멈춰(원인 미상, 아래 `SKILL.md` "알려진 막힘") 어느 여정도 끝까지 돌려 보지 못했다.
> 처음 실제로 돌린 사람이 틀린 라벨·순서를 고치고 이 줄을 지운다. (포스트잇은 처음부터 실행으로 썼다 — `memo.md`)

## 기본 전제

- `launch.sh`로 새로 설치한 상태(빈 데이터). 온보딩 `건너뛰기`를 누르면 `오늘` 탭이 첫 화면이다.
- 시드는 사진 AI 붙여넣기로 넣는다(`ai-paste.md`). CSV·DB 직접 쓰기로 넣지 않는다.
- 날짜는 **오늘 기준**으로 만든다(`date +%F`). 고정 날짜를 쓰면 오늘 탭 여정이 날짜에 따라 깨진다.
- 이번 실행이 띄우지 않은 인스턴스는 조작하지 않는다.

## 조작 규칙

- 손잡이는 화면 글자와 시맨틱스 라벨이다. 좌표는 `snapshot_ui`에 안 나올 때만.
- 명령·라벨은 글자 그대로 쓴다(띄어쓰기·가운뎃점 포함).
- 데이터를 바꾼 여정 뒤에는 `설정 › 전체 데이터 초기화` 또는 `launch.sh`(재설치)로 시드 상태로 되돌린다. 증거는 지우지 않는다.

## 증명과 건너뜀 보고

- 동작 전·후를 함께 남긴다. 몇 초짜리 UI(스낵바·도장)는 녹화.
- 데이터 변경은 두 번째 화면 또는 `db.sh` 조회로 저장된 값을 다시 읽어 증명한다.
- 증거마다 기능 ID와 사용한 진입점을 적는다.
- 닿지 못한 경로는 시도한 명령과 충족되지 않은 전제를 함께 보고한다. 건너뛴 진입점을 다른 경로로 검증했다고 보고하지 않는다.

## 기능 파일 규약

H1 + 사용자에게 보이는 동작 한 문단, 그 뒤 H2 넷을 이 순서로: `세부 기능` · `들어가는 길 (사용자 시점)` · `<도구>로 조작하기` · `함정`.
구현 세부는 넣지 않는다. 사용자 경로, 안정적인 손잡이, 필요한 상태, 명령, 관찰 가능한 증명만 쓴다.

## 기능

- [사진 AI 붙여넣기](./ai-paste.md): 입력 탭 히어로에서 AI 답을 붙여넣어 검토 대기로 넣기. 다른 여정의 시드 경로.
- [검토 대기 확정](./confirm-schedule.md): 스와이프·일괄 확정 → 목록에서 빠지고 캘린더에 생김.
- [오늘 탭 완료 도장](./today-complete.md): 오늘 업무의 체크 원 → 도장과 결산 링, `completed_at` 기록.
- [포스트잇](./memo.md): 켜기·쓰기·색 규칙·날짜 → 캘린더·업무로 등록·삭제·휴지통 복구·끌어 순서 바꾸기·끄기. **실행 증명됨(2026-11-03)**.

## 아직 지도에 없는 것

캘린더 편집 시트·스와이프, 휴지통 복구, 작년 CSV 가져오기(`/import`), 설정(테마·알림·도장 모양), 선택 기능(지도 기록·장소 예약·출퇴근 버스). 유지 점검 때 하나씩 더한다.
