# 포스트잇 (선택 탭)

일정으로 정식 등록하기 애매한 것을 쪽지로 붙여 두는 보드다. 기본 꺼짐이고 `설정 › 기능 관리 › 포스트잇`으로 켠다. 날짜를 붙이면 그날 캘린더 목록·격자에 보이고, 쪽지 시트에서 업무·행사로 등록하면 일정이 생기고 쪽지는 휴지통으로 간다. 꾹 눌러 끌어 순서를 바꾼다.

**실행 증명: 2026-11-03**, iPhone 17 / iOS 27, v1.4.4(143) debug, 증거 `~/.planroutine/verify/20261103-190459/memo/`. 아래 라벨·순서는 그 실행에서 확인한 것이다.

## 세부 기능

- 켜기: `기능 관리`의 `내 탭`이 4/6 → 5/6, 탭바에 `포스트잇`이 `설정` 바로 앞에 생긴다.
- 빈 보드: `붙여 둔 포스트잇이 없습니다` / `오른쪽 아래 + 를 누르면 쪽지를 붙일 수 있어요`.
- `+`(`포스트잇 붙이기`) → 새 쪽지 시트. 키보드가 바로 오른다. 새 쪽지에는 `저장`만 있고 `삭제`·`일정으로 등록`이 없다.
- 새 쪽지 색은 **맨 앞 쪽지와 다른 색 중 무작위**(첫 쪽지 노랑 → 둘째 분홍으로 확인). 저장하면 맨 앞에 붙는다(`sort_order` 최소값 − 1).
- 날짜 칩 → 날짜 선택 → `날짜 11월 5일 (목)` + `날짜 삭제`. 보드 카드에는 붙인 날짜만 오른쪽 아래(`11.5 (목)`), 만든 날은 없다.
- 캘린더: 격자 그날 칸에 **네모** 표시(일정 점과 다르다), 일정이 없는 날도 섹션이 생기고 쪽지 카드(`교과서 신청, 포스트잇`)가 뜬다. 카드는 **스와이프되지 않는다**.
- 기존 쪽지 시트: 맨 아래 한 줄 `삭제 · 일정으로 등록 ▾ · 저장`. `▾` 메뉴 = `캘린더에 정식 일정으로` / `업무로 등록` / `행사로 등록`.
- `업무로 등록` → 같은 날 업무 이벤트(`kind=task`, `schedule_id` NULL) + 쪽지 휴지통 + 알림 `일정으로 등록하고 포스트잇은 휴지통으로 옮겼어요`. 격자 표시가 네모에서 점으로 바뀐다.
- `삭제` → 확인 창 없이 휴지통.
- 휴지통: 한 목록, 최근에 지운 것이 위, 부제 `포스트잇 · 삭제 오늘`, 줄마다 `<제목>, 복구` / `<제목>, 영구 삭제`. 일정으로 바꾼 쪽지를 복구하면 일정과 쪽지가 둘 다 남는다(설계대로).
- 꾹 눌러 끌기: 들린 쪽지를 다른 자리에 놓으면 순서가 바뀌고 `sort_order`가 다시 쓰인다.
- 끄기: 탭이 사라지고 캘린더의 쪽지 카드·네모도 사라진다. `memos` 행은 남는다.

## 들어가는 길 (사용자 시점)

1. `launch.sh` → `건너뛰기`(첫 화면은 캘린더다).
2. `설정` → `기능 관리` → `포스트잇 / 탭 · …` 스위치.
3. 탭바 `포스트잇` → `+`.
4. 캘린더 확인은 탭바 `캘린더`(기능 관리 화면에도 `캘린더` 글자가 있어 라벨로 누르면 엉뚱한 줄을 잡는다 → 탭바 좌표 `150,812`, 포스트잇을 켠 5탭에서는 `120,812`).

## ax.sh로 조작하기

iOS 27에서는 MobileBuildMCP `snapshot_ui`가 `Timed out creating the simulator remote automation session`으로 실패했다. `scripts/ax.sh`(번들 AXe)로 했다.

```bash
A=.claude/skills/verify/scripts/ax.sh; V=.claude/skills/verify/scripts
$A tap 설정; $A tap "기능 관리"; $A tap "포스트잇 / 탭"
$A xy 281 812                          # 탭바 포스트잇(5탭일 때)
$A tap "포스트잇 붙이기"; $A ko "교과서 신청"
$A tap 날짜                             # 키보드가 떠 있으면 첫 탭이 버려진다 → 안 열리면 한 번 더
$A tap "5, 2026년 11월 5일"; $A tap 확인; $A tap 저장
$V/db.sh "select id, text, color, memo_date, sort_order, deleted_at from memos order by sort_order"
$V/db.sh "select title, event_date, kind, schedule_id from calendar_events where deleted_at is null"
```

끌기는 한 HID 세션에서 누르기 → 1초 → 조금씩 옮기기 → 떼기:

```bash
AXE=$(ls ~/.npm/_npx/*/node_modules/mobilebuildmcp/bundled/axe | head -1)
D=$(mktemp)
{ echo "touch -x 296 -y 206 --down"; echo "sleep 1.0"
  for x in $(seq 290 -8 105); do echo "touch -x $x -y 206 --down"; echo "sleep 0.03"; done
  echo "sleep 0.5"; echo "touch -x 105 -y 206 --up"; } > "$D"
$AXE batch --udid 832373BE-F5D2-4FDE-BCF7-65A9D8CD6592 --file "$D"; rm -f "$D"
```

알림은 녹화로 잡는다(`SKILL.md` 증거 절). 장면은 `ffmpeg -ss <초> -i clip.mp4 -frames:v 1 out.png`.

## 함정

- **AXe 기본 `tap`은 보드 쪽지를 열지 못한다** — 손가락을 오래 붙여 `LongPressDraggable`이 끌기로 받는다. `ax.sh`는 0.05초 터치를 쓴다. 앱 결함이 아니다.
- **`▾` 메뉴 항목의 접근성 좌표가 틀린다**(화면 위쪽 `52,232`로 나온다, 실제는 약 `124,695`). 메뉴가 떠 있는 동안 트리 전체 좌표가 어긋났다 → 스크린샷에서 재서 `xy`로 누른다.
- 키보드가 떠 있을 때 시트 밖·시트 버튼의 **첫 탭이 버려지는 일**이 잦았다. 누른 뒤 `ls`로 바뀌었는지 보고 한 번 더.
- 한글: `ax.sh ko`(두벌식 키로 변환). AXe `key 40`(Return)·`key 42`(지우기)는 짧게 보내면 버려진다 → `--duration 0.1`. 여러 줄은 화면 키보드 `Return 키`를 좌표로 누르는데, 조합 중이면 첫 Return이 조합만 끝내 **빈 줄이 하나 더** 생긴다. mobile MCP `type_keys`는 자기 도우미 앱을 앞으로 띄워 공직플랜을 뒤로 민다.
- 여러 줄 입력칸의 `AXValue`는 줄바꿈을 잃거나 늦게 갱신된다 → 입력 결과는 스크린샷으로 본다.
- 관찰(미조사): 캘린더에서 변환 알림이 4초 동안 오른쪽 아래 `+` 버튼을 덮는다.
