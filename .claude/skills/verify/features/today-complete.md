# 오늘 탭 완료 도장

오늘 탭은 오늘 처리할 **업무**만 보여 준다(행사는 안 뜬다). 행 왼쪽 체크 원을 누르면 그 자리에 골드 도장이 찍히고 위쪽 결산 링이 차오르며, 다시 누르면 제자리에서 흐려지며 취소된다.

## 세부 기능

- `today-list`: 오늘 날짜의 확정된 업무만 보인다. 행사는 빠진다.
- `today-complete`: 체크 원 → 도장 + `오늘 N건 남았습니다` 감소, 모두 끝나면 `오늘 업무 모두 완료했네요!`.
- `today-undo`: 다시 누르면 완료 취소, 행 자리는 그대로.

## 들어가는 길 (사용자 시점)

- 앱 첫 화면 = 탭바 `오늘`.

## AXe·snapshot_ui로 조작하기

전제:

- 오늘 날짜 업무 2건을 붙여넣고(`ai-paste.md`의 `paste-task`) 확정했다(`confirm-schedule.md`). 대조용으로 오늘 날짜 행사 1건도 확정해 둔다.

- **목록 확인.** 탭바 `오늘` → 업무 2건이 보이고 행사 제목은 없다. 결산 문구 `오늘 2건 남았습니다`.
- **완료.** 녹화를 켠 뒤 `snapshot_ui`에서 `검증 업무 A, 일정 완료` 버튼을 `tap`. 도장이 찍히고 `오늘 1건 남았습니다`.
- **모두 완료.** `검증 업무 B, 일정 완료`를 `tap` → `오늘 업무 모두 완료했네요!`.
- **취소.** `검증 업무 A, 일정 완료`를 다시 `tap` → 도장이 흐려지며 사라지고 `오늘 1건 남았습니다`.
- **증명.** `db.sh "SELECT title, completed_at FROM calendar_events WHERE deleted_at IS NULL AND kind='task'"` → B만 `completed_at`이 있다.

## 함정

- `snapshot_ui`는 체크 상태(`checked`)를 스위치 값으로만 보여 준다. 완료 여부는 결산 문구와 DB로 본다.
- 도장 애니메이션은 1초 안팎이다. 스크린샷 대신 녹화.
- 자정을 넘기면 오늘 기준이 바뀐다. 앱을 다시 띄워 기준일을 새로 잡는다.
- 지난 날짜 업무는 `기한이 지난` 섹션에 접혀 있다. 시드를 오늘 날짜로 만드는 이유다.
